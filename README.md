Movie-Ticket-Booking-Management
CineWave Entertainment manages movie ticket bookings across multiple theatres and locations. Ticket booking and tracking processes are currently handled manually through emails and offline systems, leading to delays, lack of visibility, and inefficiencies in managing bookings and customer communication.

CineWave Entertainment wants to build a Movie Ticket Booking Management application on Pega Platform™ to:

Allow customers to request movie ticket bookings.

Enable staff to manage show details and seating availability

Capture customer confirmations before final booking

Process booking requests and track status

Notify customers upon booking confirmation

Project Objectives :

Students are expected to:

Design a case lifecycle for ticket booking

Define and implement user interactions

Model required data structures

Configure basic business logic and automation

Ensure smooth flow from booking request to ticket confirmation
